What the demonstration shows

  1. The user reviews the configured pace, write interval and active duration, then explicitly taps Start in Realtime mode.
  2. The user leaves the app. A visible foreground notification identifies realtime manual input and shows progress while the service continues.
  3. The user returns to the app and taps Pause, then Resume. Pausing stops elapsed-time estimation and flushes the partial batch.
  4. The user taps End. The final partial batch is written, the service ends, and the normal Free-plan cooldown is displayed.
  5. The Health screen shows the emulator's locally created records and Health Connect integration.

This is pace/time estimation and local Health Connect synchronization using a dataSync foreground service. It is not sensor counting, GPS tracking or medical monitoring. Writes are marked as manual input. Health Connect and notification permissions were granted through Android's normal permission screens before this recording. No test data is written to a real person's device.
